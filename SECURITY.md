# Security Policy

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities or exposed
credentials.

Use GitHub's private vulnerability reporting feature for this repository. If
that feature is unavailable, contact the repository owner privately.

Include:

- The affected component and version or commit.
- Steps to reproduce the issue.
- The expected impact.
- Any suggested remediation.

Do not access, modify, or retain data that does not belong to you while
researching a vulnerability.
